# Project rules

- Preserve the existing page-component/file-route split; new public content gets a leaf route with server-rendered metadata so crawlers and visitors see the same page.
- Keep gift-card terms and calendar validity in the shared policy module and test their concrete values; do not activate checkout until the provider, price, and session duration are confirmed.
- Use the shared gift-card section only on the homepage and the dedicated gift-card page for details, preserving the existing photos and page order.
